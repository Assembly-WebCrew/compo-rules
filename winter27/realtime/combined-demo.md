# Combined Demo

Refer to the [General rules](../general.md) with the following additions:

This competition celebrates creative real-time audiovisual demos. If you can code it and it runs on a publicly available platform, it belongs here. Beginner entries participate under the same rules as all other entries.

Entries may target any generally available platform, including but not limited to:

- Modern desktop platforms such as Windows, macOS, and Linux.
- Retro and oldskool platforms such as C64, Amiga, Atari ST, NES, SNES, Mega Drive, and Game Boy.
- Fantasy consoles and virtual platforms such as PICO-8, TIC-80, Picotron, Quadplay, Voxatron, and IBNIZ.
- Other accessible environments such as WebGL, DOS, Java, or similar software environments.

If your entry requires custom or one-off hardware, such as an FPGA, microcontroller, or mechanical device, submit it to Wild (with AI) instead.

- Realtime entries may include music and graphics that compete at the same event.
- Commercial and non-commercial engines, frameworks, libraries, plugins, and other production tools may be used. Previously released components and assets, such as fonts and system samples, are also allowed when they are not the main creative effort and you have the right to use them.
- List third-party material and significant external technology used in the production in the entry form or accompanying readme. Creative Commons and Public Domain material must include a citation and a link to the source.
- Generative AI may assist with programming, including agentic coding. The entry must not be primarily generated by AI: its main creative and technical contribution must come from the participating artist or group.
- If generative AI is used directly to create the submitted entry, enable the **Gen AI** option in the entry form and briefly describe how it was used. AI-generated graphics, music, audiovisual material, and other creative assets may not be used as content in the entry.
- Engines and other production tools are allowed even if generative AI was used to develop them. Using such a tool does not make the entry AI-generated, and the **Gen AI** option is not required unless generative AI was used directly to create the submitted entry.
- Fan art using copyrighted characters or works is not allowed.
- The entry must be executable. Pure video playback, rendered animations, and executables that only contain an animation and a player are not allowed.
- The production must run in real time and show in a similar manner each time it is executed.
- The production may use temporary files where the platform provides them but must not permanently modify system settings.
- The demo may be up to 8 minutes long, but organizers may stop it before the end.
- The compressed submission archive may be at most 2 GB. Keep the size reasonable on other platforms too.
- A screenshot must be submitted with the entry.
- Submit the executable and all other files needed to run it, plus a readme with platform and launch instructions.
- Entries that do not run on the compo PC must include a high-quality video capture, preferably 1080p60. Real-hardware capture is preferred, but emulator capture is acceptable. See Capture assistance in the general rules.
- Entries can be tested at CompoBase or by prior arrangement with the compo crew. Arrange testing early enough to fix any problems.
- Browser-based entries are accepted. They are run in a mainstream desktop browser on the compo PC - Chrome by default. State in the submission notes if the entry needs Firefox or another browser. The entry must be fully self-contained as a single file, with no external resources loaded from the network. Browsers differ, so test the entry on the compo machines. Tools such as [WebDemoExe](https://github.com/pandrr/WebDemoExe) can be used to package a browser demo into a more controlled runtime environment.
- The entry must be launchable using the normal method for its platform, such as an executable, cartridge, disk image, or web player.
- Hide the mouse cursor where applicable.
- The user must be able to exit at any time using the platform's standard quit method, such as ESC on a PC, where the platform supports this.
- Windows intros should avoid importing by ordinal from DLLs with non-fixed ordinals.
- Size-limited intros are welcome. The platform and size will be shown on the information slide.

Remote entries are welcome.
